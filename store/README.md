# حزمة النشر في المتاجر — Lin Go 1.7.8

هذه الحزمة تجمع مواد المتجر والمراجع اللازمة لنشر **Lin Go 1.7.8** في متجر تطبيقات معروف. الرفع الفعلي يحتاج حساب مطوّر موثّقًا وموافقة صريحة على شروط المتجر؛ لا يمكن إنشاء الحساب أو قبول الشروط نيابة عن صاحب التطبيق.

## حالة الحزمة

| العنصر | الحالة |
|---|---|
| مواد المتجر (لقطات، أيقونة، صورة بارزة) | جاهزة |
| الصفحات القانونية (الخصوصية، الشروط، الترخيص) | جاهزة للمراجعة والنشر |
| APK مباشر موقّع | جاهز ومنشور عبر الموقع |
| نسخة متجر بدون تحديث ذاتي | جاهزة (APK + AAB) |
| قائمة المتجر بالعربية | مسودة جاهزة |
| Data safety وتقييم المحتوى | مسودات جاهزة |
| اختيار المتجر والجمهور المستهدف | بانتظار قرار صاحب التطبيق |
| الرفع والمراجعة | بانتظار حساب المتجر |

- شهادة التوقيع SHA-256: `3c224d32dbda222f400b3b5a18b1787ff99f219ba33856bf4f3d00e09307ff4e`
- يجب الاحتفاظ بـ `android/keystore.properties` وملف المفتاح في مكان آمن. فقدان المفتاح يمنع تحديث التطبيق مباشرةً أو في المتجر.

## قرارات مطلوبة قبل الرفع

1. **المتجر:** Samsung Galaxy Store (مجاني، موصى به) أو Google Play (25 دولارًا لمرة واحدة + متطلبات إضافية) أو Huawei AppGallery (مجاني مع قيود خدمات Google).
2. **الجمهور المستهدف:** 13+ (موصى به) أو الأطفال/العائلات (يتطلب مراجعة سياسات إضافية).
3. **استراتيجية التوقيع على Google Play:** هل يقبل صاحب التطبيق أن يدير Play التوقيع (قد يتوقف تحديث APK المباشر)، أم نستخدم حزمة منفصلة لـ Play؟
4. **قبول الشروط القانونية** الخاصة بالمتجر، وتأكيد أن الصفحات القانونية تعكس النشاط الفعلي.

بعد هذه القرارات يمكن بناء نسخة المتجر ورفعها. راجع `publishing-guide-ar.md` للتفاصيل.
