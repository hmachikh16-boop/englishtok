# EnglishTok 📱🎬

تطبيق تعليمي متكامل للغة الإنجليزية مستوحى من أسلوب تيك توك في عرض الفيديوهات العمودية القصيرة، ومصمم خصيصاً لهواتف وتابلت Android مع دعم كامل للويب وتصدير APK عبر Capacitor.

---

## 🌟 مميزات التطبيق

1. **خلاصة فيديوهات عمودية (Vertical Feed) بأسلوب TikTok:**
   - التمرير العمودي (سحب لأعلى ولأسفل) للتنقل السريع بين الدروس.
   - تشغيل وإيقاف بالنقر المفرد، مع دعم النقر المزدوج للإعجاب (Double tap to like) مع قلوب متحركة ومؤثرات صوتية.
   - أزرار تفاعلية: الإعجاب، المفضلة، بنك الكلمات، التحكم بالسرعة (1x / 0.75x / 0.5x)، إعادة الجملة، ومشاركة الدرس.
   - ترجمة فورية متزامنة (إنجليزي + عربي) مع إمكانية إخفائها أو جعلها بالإنجليزية فقط لتحدي الاستماع.
   - إمكانية النقر على أي كلمة في الترجمة للاستماع لنطقها الصوتي الفردي ورؤية معناها.

2. **مشاهد رسوم متحركة حية (Animated Cartoon Scenes):**
   - محادثات ثنائية بين شخصيات كرتونية معبرة (أليكس، إيما، سارة، عمر، صوفيا، ليام، مايا، جاك، د. إيميلي، نوح، مايك، زارا، إلخ).
   - حركات فم متزامنة عند التحدث (Lip sync / Talking mouth)، وبوب متحرك للشخصية النشطة، وفقاعات كلام كرتونية (Speech Bubbles).
   - خلفيات ملونة تحاكي الواقع (مقهى، مطار، مكتب عمل، متجر ملابس، عيادة طبية، حديقة، شوارع مدينة).

3. **نطق بشري طبيعي بدون إنترنت (Offline TTS):**
   - استغلال Web Speech API و Web Audio API لتوليد النطق والمؤثرات الصوتية محلياً 100% دون الحاجة لاتصال بالإنترنت أو مفاتيح خارجية.
   - دعم اللهجتين الأمريكية (US) والبريطانية (UK).

4. **نظام التلعيب والمكافآت (Gamification):**
   - حساب نقاط الخبرة XP والترقية بين الرتب (مبتدئ، مستكشف، متحدث واثق، محاور طليق، خبير).
   - عداد السلسلة اليومية (Daily Streak) لتشجيع الاستمرار.
   - اختبارات سريعة (Quizzes) تفاعلية نهاية كل درس مع تعليقات فورية بالعربية.
   - أوسمة إنجاز (Badges) تُفتح تلقائياً عند تحقيق الأهداف.

5. **بنك الكلمات والبطاقات الذكية (Vocab Bank & Flashcards):**
   - حفظ المفردات ومراجعتها بنظام البطاقات القلابة (Flashcards).
   - تحديد الكلمات المتقنة (Mastered Words).
   - دليل النطق الصوتي الفونيمات (IPA) وجمل تطبيقية واقعية.

6. **شريط تنقل سفلي متوافق مع معايير اللمس:**
   - الرئيسية (Feed)
   - التصنيفات (Categories)
   - الكلمات (Vocab Bank)
   - التقدم (Progress & Badges)
   - الإعدادات ودليل APK (Settings & Capacitor Guide)

## 📂 بنية المشروع وإدارة المحتوى

تم عزل وتفصيل بيانات الدروس بالكامل عن واجهات العرض لسهولة التطوير:

```
src/
├── types/
│   └── index.ts               # تعريفات الواجهات والأنواع (Lesson, Character, Vocab, Quiz)
├── data/
│   └── lessons.ts             # قاعدة بيانات الدروس، التصنيفات، والشخصيات (مكان إضافة الدروس)
├── services/
│   ├── speechService.ts       # محرك النطق الصوتي والمؤثرات الصوتية التخليقية
│   └── storageService.ts      # التخزين المحلي والتقدم والسلاسل اليومية
├── components/
│   ├── video/
│   │   ├── CartoonScene.tsx   # محرك الرسوم المتحركة الكرتونية SVG
│   │   ├── VideoOverlay.tsx   # عناصر التحكم الجانبية وأزرار التفاعل وشريط الترجمة
│   │   └── FeedPlayer.tsx     # مشغل الفيديوهات العمودية وحركات السحب
│   ├── quiz/
│   │   └── LessonQuizModal.tsx# نافذة الاختبارات التفاعلية وحساب نقاط XP
│   ├── vocab/
│   │   ├── VocabDrawer.tsx    # درج مفردات الفيديو الحالي
│   │   └── VocabTab.tsx       # تبويب بنك الكلمات والبطاقات التعليمية
│   ├── categories/
│   │   └── CategoriesTab.tsx  # تبويب التصنيفات والفلترة حسب المستوى (A1, A2, B1, B2)
│   ├── progress/
│   │   └── ProgressTab.tsx    # تبويب الإحصائيات والرتب والأوسمة
│   ├── settings/
│   │   └── SettingsTab.tsx    # تبويب الإعدادات ودليل تحويل Capacitor
│   └── navigation/
│       ├── TopBar.tsx         # شريط الرأس مع رصيد XP وزر تبديل إطار الهاتف/التابلت
│       └── BottomTabBar.tsx   # شريط التنقل السفلي الثابت
├── App.tsx                    # المكون الرئيسي
└── index.css                  # قواعد CSS والأنيميشن
```


## 📲 خطوات تحويل المشروع إلى تطبيق أندرويد (APK) باستخدام Capacitor

تم تجهيز ملف `capacitor.config.json` في المشروع. لتحويله محلياً على جهازك إلى ملف APK، اتبع الخطوات التالية:

### 1. تثبيت حزم Capacitor:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
```

### 2. بناء ملفات الويب الإنتاجية:
```bash
npm run build
```

### 3. إضافة منصة أندرويد:
```bash
npx cap add android
```

### 4. مزامنة التغييرات:
```bash
npx cap sync android
```

### 5. فتح المشروع في Android Studio لتوليد الـ APK:
```bash
npx cap open android
```
داخل **Android Studio**:
- اذهب إلى القائمة: `Build` ➔ `Build Bundle(s) / APK(s)` ➔ `Build APK(s)`.
- سينتج لك ملف `app-debug.apk` أو `app-release.apk` جاهزاً للتثبيت المباشر على أي هاتف أو تابلت أندرويد.
