# EnglishTok 📱🎬

تطبيق تعليمي متكامل للغة الإنجليزية مستوحى من أسلوب تيك توك في عرض الفيديوهات العمودية القصيرة، ومصمم خصيصاً لهواتف وتابلت Android مع دعم كامل للويب وتصدير APK عبر Capacitor.

---

## 🌟 مميزات التطبيق

1. **خلاصة فيديوهات عمودية (Vertical Feed) بأسلوب TikTok:**
   - التمرير العمودي (سحب لأعلى ولأسفل) للتنقل السريع بين الدروس.
   - تشغيل وإيقاف بالنقر المفرد، مع دعم النقر المزدوج للإعجاب (Double tap to like) مع قلوب متحركة ومؤثرات صوتية.
   - أزرار تفاعلية: الإعجاب، المفضلة، بنك الكلمات، التحكم بالسرعة (1x / 0.75x / 0.5x)، إعادة الجملة، ومشاركة الدرس.
   - ترجمة فورية متزامنة (إنجليزي + عربي) مع إمكانية إخفائها أو جعلها بالإنجليزية فقط لتحدي الاستماع.
   - إمكانية النقر على أي كلمة في الترجمة للاستماع لنطقها الصوتي الفردي ورؤية معناها.

2. **مشاهد رسوم متحركة حية (Animated Cartoon Scenes):**
   - محادثات ثنائية بين شخصيات كرتونية معبرة (أليكس، إيما، سارة، عمر، صوفيا، ليام، مايا، جاك، د. إيميلي، نوح، مايك، زارا، إلخ).
   - حركات فم متزامنة عند التحدث (Lip sync / Talking mouth)، وبوب متحرك للشخصية النشطة، وفقاعات كلام كرتونية (Speech Bubbles).
   - خلفيات ملونة تحاكي الواقع (مقهى، مطار، مكتب عمل، متجر ملابس، عيادة طبية، حديقة، شوارع مدينة).

3. **نطق إنجليزي سحابي واضح:**
   - استخدام Google Cloud Text-to-Speech Neural2 بصوت `en-US` افتراضيًا، مع اختيار `en-GB` من الإعدادات.
   - النص الإنجليزي وحده يُرسل للنطق؛ الترجمة العربية تبقى مكتوبة على الشاشة.
   - يتطلب اتصال إنترنت ومفتاحًا محفوظًا في بيئة الخادم. لا يُستخدم أي صوت نظام أو صوت عربي كبديل.
   - مفتاح المزود غير مضبوط افتراضيًا، وحد الاستخدام الافتراضي 10,000 حرف يوميًا مع سقف 30 طلبًا في الدقيقة لكل عنوان IP. هذه الحدود في ذاكرة عملية الخادم وتُعاد عند إعادة تشغيله.

4. **نظام التلعيب والمكافآت (Gamification):**
   - حساب نقاط الخبرة XP والترقية بين الرتب (مبتدئ، مستكشف، متحدث واثق، محاور طليق، خبير).
   - عداد السلسلة اليومية (Daily Streak) لتشجيع الاستمرار.
   - اختبارات سريعة (Quizzes) تفاعلية نهاية كل درس مع تعليقات فورية بالعربية.
   - أوسمة إنجاز (Badges) تُفتح تلقائياً عند تحقيق الأهداف.

5. **بنك الكلمات والبطاقات الذكية (Vocab Bank & Flashcards):**
   - حفظ المفردات ومراجعتها بنظام البطاقات القلابة (Flashcards).
   - تحديد الكلمات المتقنة (Mastered Words).
   - دليل النطق الصوتي الفونيمات (IPA) وجمل تطبيقية واقعية.

6. **شريط تنقل سفلي متوافق مع معايير اللمس:**
   - الرئيسية (Feed)
   - التصنيفات (Categories)
   - الكلمات (Vocab Bank)
   - التقدم (Progress & Badges)
   - الإعدادات ودليل APK (Settings & Capacitor Guide)

### إعداد النطق السحابي (اختياري)

لا يُفعّل النطق السحابي تلقائيًا ولا يُنشئ المشروع حسابًا أو مفتاحًا. قبل التفعيل، راجع [أسعار Google Cloud Text-to-Speech](https://cloud.google.com/text-to-speech/pricing) و[الحصص والحدود](https://cloud.google.com/text-to-speech/quotas) و[شروط Google Cloud](https://cloud.google.com/terms/). أصوات Neural2 تُحاسب بحسب عدد الأحرف؛ السعر المنشور هو 16 دولارًا لكل مليون حرف بعد الحصة المجانية الشهرية البالغة مليون حرف لهذا النوع، وقد تتغير الأسعار والحصص. يتطلب الاستخدام إنشاء مشروع Google Cloud وتفعيل Text-to-Speech وربط الفوترة. التسجيل في التجربة المجانية قد يتطلب وسيلة دفع، وقد يضع المزود حجز تحقق مؤقتًا. لا تضف وسيلة دفع أو تفعّل الفوترة إلا بعد مراجعة شروط Google والموافقة عليها.

لتشغيل الخدمة بعد إعداد المزود والموافقة على إعداد حسابه:

1. انسخ `.env.example` إلى `.env` على الخادم، وأدخل المفتاح في `GOOGLE_TTS_API_KEY` فقط. لا تستخدم بادئة `VITE_` للمفتاح، ولا تضع المفتاح في مستودع عام أو في تطبيق Android.
2. اترك `TTS_DAILY_CHARACTER_LIMIT` على قيمته الافتراضية أو اخفضها. يُحتسب الحد قبل إرسال الطلب لتقليل احتمال تجاوز السقف عند الطلبات المتزامنة. الحد ومحددات الطلبات في ذاكرة الخادم وتُعاد عند إعادة تشغيله؛ وهي دفاعات مساعدة وليست بديلًا عن تنبيهات الميزانية والحصص في Google Cloud.
3. شغّل `npm run dev` للتطوير، أو `npm run build` ثم `npm start` للإنتاج. يجب نشر خادم Node مع الواجهة؛ النشر كملفات ثابتة فقط لن يوفّر نقطة `/api/tts`.
4. لتطبيق Capacitor أو واجهة مستضافة منفصلة، اضبط `VITE_TTS_API_URL` على عنوان API العام، وأضف أصل التطبيق إلى `TTS_ALLOWED_ORIGINS` في الخادم. عنوان API ليس سرًا؛ المفتاح يبقى على الخادم.

تُرسل الجملة الإنجليزية إلى Google لإنتاج الصوت، ولا تُرسل الترجمة العربية. لن يعمل النطق عند انقطاع الإنترنت أو غياب مفتاح الخادم، ولن يعود إلى أصوات Windows/المتصفح. مؤثرات الواجهة الصوتية تبقى محلية.

## 📲 خطوات تحويل المشروع إلى تطبيق أندرويد (APK) باستخدام Capacitor

تم تجهيز ملف `capacitor.config.json` في المشروع. لتحويله محلياً على جهازك إلى ملف APK، اتبع الخطوات التالية:

### 1. تثبيت حزم Capacitor:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
```

### 2. بناء ملفات الويب الإنتاجية:
```bash
npm run build
```

### 3. إضافة منصة أندرويد:
```bash
npx cap add android
```

### 4. مزامنة التغييرات:
```bash
npx cap sync android
```

### 5. فتح المشروع في Android Studio لتوليد الـ APK:
```bash
npx cap open android
```
داخل **Android Studio**:
- اذهب إلى القائمة: `Build` ➔ `Build Bundle(s) / APK(s)` ➔ `Build APK(s)`.
- سينتج لك ملف `app-debug.apk` أو `app-release.apk` جاهزاً للتثبيت المباشر على أي هاتف أو تابلت أندرويد.
