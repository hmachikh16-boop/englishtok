# EnglishTok 📱🎬

تطبيق تعليمي متكامل للغة الإنجليزية مستوحى من أسلوب تيك توك في عرض الفيديوهات العمودية القصيرة، ومصمم خصيصاً لهواتف وتابلت Android مع دعم كامل للويب وتصدير APK عبر Capacitor.

لإعداد النشر التلقائي، توقيع إصدارات Android، تحديث APK والمحتوى دون مسح تقدم المتعلم، راجع [دليل النشر والتحديث](./DEPLOYMENT.md).

---

## 🌟 مميزات التطبيق

1. **خلاصة فيديوهات عمودية (Vertical Feed) بأسلوب TikTok:**
   - التمرير العمودي (سحب لأعلى ولأسفل) للتنقل السريع بين الدروس.
   - تشغيل وإيقاف بالنقر المفرد، مع دعم النقر المزدوج للإعجاب (Double tap to like) مع قلوب متحركة ومؤثرات صوتية.
   - أزرار تفاعلية: الإعجاب، المفضلة، بنك الكلمات، التحكم بالسرعة (1x / 0.75x / 0.5x)، إعادة الجملة، ومشاركة الدرس.
   - ترجمة فورية متزامنة (إنجليزي + عربي) مع إمكانية إخفائها أو جعلها بالإنجليزية فقط لتحدي الاستماع.
   - إمكانية النقر على أي كلمة في الترجمة للاستماع لنطقها الصوتي الفردي ورؤية معناها.

2. **مشاهد رسوم متحركة حية (Animated Cartoon Scenes):**
   - محادثات ثنائية بين شخصيات كرتونية معبرة (أليكس، إيما، سارة، عمر، صوفيا، ليام، مايا، جاك، د. إيميلي، نوح، مايك، زارا، إلخ).
   - حركات فم متزامنة عند التحدث (Lip sync / Talking mouth)، وبوب متحرك للشخصية النشطة، وفقاعات كلام كرتونية (Speech Bubbles).
   - خلفيات ملونة تحاكي الواقع (مقهى، مطار، مكتب عمل، متجر ملابس، عيادة طبية، حديقة، شوارع مدينة).

3. **نطق احترافي مضمّن داخل التطبيق (Bundled Studio Voice):**
   - كل أسطر الحوار في الدروس مسجّلة مسبقًا بصوت بشري عالي الجودة (Opus 24 kbps داخل ملفات Ogg) ومضمّنة في التطبيق نفسه، فيُسمع الصوت فورًا دون شريط تحميل ودون انتظار.
   - لا يتطلب مفتاح API أو حسابًا أو فوترة، ويعمل الصوت دون اتصال بالإنترنت بعد التثبيت.
   - خيار النطق الفرنسي مخصص للنصوص الفرنسية؛ نصوص المنهج الإنجليزية تُقرأ دائمًا بالصوت الإنجليزي المضمّن، والترجمة العربية تبقى مكتوبة على الشاشة.
   - الدروس التأسيسية الـ16 لها مقاطع مضمّنة تعمل دون اتصال. الدروس الموسّعة الـ184 تستخدم صوت الجهاز مؤقتًا وتتحوّل إليه تلقائيًا عند غياب المقطع المضمّن، إلى أن تُولَّد مقاطعها بـ`npm run speech:generate`.

4. **نظام التلعيب والمكافآت (Gamification):**
   - حساب نقاط الخبرة XP والترقية بين الرتب (مبتدئ، مستكشف، متحدث واثق، محاور طليق، خبير).
   - عداد السلسلة اليومية (Daily Streak) لتشجيع الاستمرار.
   - اختبارات سريعة (Quizzes) تفاعلية نهاية كل درس مع تعليقات فورية بالعربية.
   - أوسمة إنجاز (Badges) تُفتح تلقائياً عند تحقيق الأهداف.

5. **بنك الكلمات والبطاقات الذكية (Vocab Bank & Flashcards):**
   - حفظ المفردات ومراجعتها بنظام البطاقات القلابة (Flashcards).
   - تحديد الكلمات المتقنة (Mastered Words).
   - دليل النطق الصوتي الفونيمات (IPA) وجمل تطبيقية واقعية.

6. **شريط تنقل سفلي متوافق مع معايير اللمس:**
   - الرئيسية (Feed)
   - التصنيفات (Categories)
   - الكلمات (Vocab Bank)
   - التقدم (Progress & Badges)
   - الإعدادات ودليل APK (Settings & Capacitor Guide)

### مكتبة الصوت المضمّنة

تُولَّد أصوات الدروس مرة واحدة أثناء التطوير بالأمر `npm run speech:generate` (السكربت `scripts/generate-speech-library.ts`)، ثم تُضمَّن داخل البناء في `public/audio/tts/<voice>/<hash>.ogg` فلا يحتاج التطبيق إلى تنزيل أي شيء عند الاستخدام.

- الأصوات من نموذج [Kokoro-82M ONNX](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX) مفتوح الأوزان (رخصة Apache-2.0): `af_heart` و`am_michael` للإنجليزية. لا يتضمن النموذج صوتًا فرنسيًا مضمّنًا، لذا تستخدم النصوص الفرنسية صوت الجهاز كخطة بديلة.
- اسم الملف = تجزئة FNV-1a 64-bit للنص بعد التطبيع (دالة `speechClipHash` في `src/services/speechClip.ts`)؛ يجب أن يتفق السكربت والتطبيق حرفيًا وإلا لن يُعثر على المقطع.
- رموز النطق (IPA) مثل `/æ/` و`/b/` تُحوَّل عند التوليد إلى صياغة طبيعية مثل «A as in Apple» بدل أن ينطقها المحرك «slash ... slash»، بينما يبقى النص المعروض كما هو.
- السكربت يولّد الصوتين الإنجليزيين لكل نص (لأن الدرس والمفردات واختبار تحديد المستوى قد يطلبون صوتًا مختلفًا)، ويتخطّى المقاطع الموجودة، فيمكن إيقافه واستئنافه بأمان، ويدعم `--limit N` لتجربة سريعة.
- الترميز بـ`ffmpeg` (`libopus`، ‏24 kbps، أحادي القناة، إعداد `voip`) وهو الأنسب للكلام البشري. يتوقع السكربت `tools/ffmpeg-tool/node_modules/ffmpeg-static/ffmpeg.exe` أو المسار في `FFMPEG_PATH`.
- `npm run speech:check` يتحقق من وجود كل المقاطع ومن سلامة نص التوليد (لا رموز IPA تُقرأ حرفيًا)، وأي نص جديد بلا مقطع يوقفه. يستخدم `npm run build` الأمر `npm run speech:audit` مؤقتًا: يعرض المقاطع الناقصة لكنه لا يوقف البناء ما دام صوت الجهاز هو الخطة البديلة. شغّل `speech:check` قبل إصدار يتطلب كل الأصوات مضمّنة.
- لم يعد التطبيق يحمّل نموذج Kokoro أو أوزان ONNX/WASM (كانت نحو 20 ميجابايت)، فانخفض حجم الحزمة وزمن الإقلاع.
- في Android لا يوفّر WebView واجهة Web Speech API، لذا يستخدم درس النطق إضافة `SpeechRecognitionPlugin` الأصلية (`android/app/src/main/java/com/englishtok/app/`) وخدمة `SpeechRecognizer`. يتضمن البيان إذن `RECORD_AUDIO` ويُطلب من المستخدم عند أول ضغط على الميكروفون.

### إضافة أو تعديل الدروس

- الدروس التأسيسية: عدّل `LESSON_SPECS` في `src/data/curriculumContent.ts`.
- الدروس الموسّعة: عدّل الملف المناسب في `src/data/expansion/` (كل ملف يحوي 23 درساً)، واتبع الدليل في `src/data/expansion/README.md`.

ثم نفّذ:

```bash
npm run content:ipa         # تحديث خريطة النطق IPA للكلمات الجديدة
npm run content:validate    # فحص 50 درساً لكل مرحلة، والمعرّفات، والاختبارات
npm run content:export      # تحديث public/content/learning-path.json
npm run speech:generate     # توليد كل المقاطع الصوتية الجديدة (يتطلب ffmpeg)
npm run speech:check        # التأكد من عدم وجود نص بلا صوت (صارم)
npm run lint && npm run build
```

حافظ على تفرّد المعرّفات `id` و`slug`، وعلى تطابق `curriculumStage` مع المرحلة المقصودة.

> ملاحظة: الدروس الموسّعة الحالية أُضيفت قبل توليد أصواتها. يعمل التطبيق فوراً عبر صوت الجهاز، ويستخدم البناء `speech:audit` فلا تتوقف عملية النشر. بعد تشغيل `npm run speech:generate` وتضمين المقاطع، استخدم `npm run speech:check` للتحقق الصارم قبل الإصدار النهائي.

## 📲 خطوات تحويل المشروع إلى تطبيق أندرويد (APK) باستخدام Capacitor

تم تجهيز ملف `capacitor.config.json` في المشروع. لتحويله محلياً على جهازك إلى ملف APK، اتبع الخطوات التالية:

### 1. تثبيت حزم Capacitor:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
```

### 2. بناء ملفات الويب الإنتاجية:
```bash
npm run build
```

### 3. إضافة منصة أندرويد:
```bash
npx cap add android
```

### 4. مزامنة التغييرات:
```bash
npx cap sync android
```

### 5. فتح المشروع في Android Studio لتوليد الـ APK:
```bash
npx cap open android
```
داخل **Android Studio**:
- اذهب إلى القائمة: `Build` ➔ `Build Bundle(s) / APK(s)` ➔ `Build APK(s)`.
- سينتج لك ملف `app-debug.apk` أو `app-release.apk` جاهزاً للتثبيت المباشر على أي هاتف أو تابلت أندرويد.
