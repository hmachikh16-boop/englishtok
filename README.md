# Lin Go 📱🎬

تطبيق تعليمي متكامل للغتين الإنجليزية والفرنسية، مستوحى من أسلوب تيك توك في عرض الفيديوهات العمودية القصيرة، ومصمم خصيصاً لهواتف وتابلت Android مع دعم كامل للويب وتصدير APK عبر Capacitor.

**⬇️ [تحميل أحدث إصدار APK](https://www.lingo.com/download)** · [الموقع الرسمي](https://www.lingo.com/) · [سياسة الخصوصية](https://www.lingo.com/legal/privacy.html)

لإعداد النشر التلقائي، توقيع إصدارات Android، تحديث APK والمحتوى دون مسح تقدم المتعلم، راجع [دليل النشر والتحديث](./DEPLOYMENT.md).

## 🌟 مميزات التطبيق

1. **خلاصة فيديوهات عمودية (Vertical Feed) بأسلوب TikTok:**
   - التمرير العمودي (سحب لأعلى ولأسفل) للتنقل السريع بين الدروس.
   - تشغيل وإيقاف بالنقر المفرد، مع دعم النقر المزدوج للإعجاب (Double tap to like) مع قلوب متحركة ومؤثرات صوتية.
   - أزرار تفاعلية: الإعجاب، المفضلة، بنك الكلمات، التحكم بالسرعة (1x / 0.75x / 0.5x)، إعادة الجملة، ومشاركة الدرس.
   - ترجمة فورية متزامنة (إنجليزي + عربي) مع إمكانية إخفائها أو جعلها بالإنجليزية فقط لتحدي الاستماع.
   - إمكانية النقر على أي كلمة في الترجمة للاستماع لنطقها الصوتي الفردي ورؤية معناها.

2. **مشاهد رسوم متحركة حية (Animated Cartoon Scenes):**
   - محادثات ثنائية بين شخصيات كرتونية معبرة (أليكس، إيما، سارة، عمر، صوفيا، ليام، مايا، جاك، د. إيميلي، نوح، مايك، زارا، إلخ).
   - حركات فم متزامنة عند التحدث (Lip sync / Talking mouth)، وبوب متحرك للشخصية النشطة، وفقاعات كلام كرتونية (Speech Bubbles).
   - خلفيات ملونة تحاكي الواقع (مقهى، مطار، مكتب عمل، متجر ملابس، عيادة طبية، حديقة، شوارع مدينة).

3. **نطق احترافي مضمّن داخل التطبيق (Bundled Studio Voice):**
   - كل أسطر الحوار في الدروس مسجّلة مسبقًا بصوت بشري عالي الجودة (Opus 24 kbps داخل ملفات Ogg) ومضمّنة في التطبيق نفسه، فيُسمع الصوت فورًا دون شريط تحميل ودون انتظار.
   - لا يتطلب مفتاح API أو حسابًا أو فوترة، ويعمل الصوت دون اتصال بالإنترنت بعد التثبيت.
   - خيار النطق الفرنسي مخصص للنصوص الفرنسية؛ نصوص المنهج الإنجليزية تُقرأ دائمًا بالصوت الإنجليزي المضمّن، والترجمة العربية تبقى مكتوبة على الشاشة.
   - جميع دروس المنهج الـ400 (المراحل الأربع) مضمّنة الآن بالصوتين الإنجليزيين `af_heart` و`am_michael`، مع نطق كلمة «blank» في أسئلة الفراغ. لا تحتاج النصوص الإنجليزية إلى صوت الجهاز، ويبقى صوت الجهاز خطة احتياطية فقط إذا تعذّر تشغيل المقطع المضمّن.

4. **نظام التلعيب والمكافآت (Gamification):**
   - حساب نقاط الخبرة XP والترقية بين الرتب (مبتدئ، مستكشف، متحدث واثق، محاور طليق، خبير).
   - عداد السلسلة اليومية (Daily Streak) لتشجيع الاستمرار.
   - اختبارات سريعة (Quizzes) تفاعلية نهاية كل درس مع تعليقات فورية بالعربية.
   - أوسمة إنجاز (Badges) تُفتح تلقائياً عند تحقيق الأهداف.
   - **مجموعة 200 بطاقة حيوان:** 50 بطاقة لكل مرحلة (25 أساسية + 25 نسخة ذهبية)، تُفتح بطاقة جديدة كل درسين، ولكل بطاقة رسالة تحفيزية ثنائية اللغة قابلة للقلب. البطاقات المقفلة لا تُقلب ولا تُقرأ قبل فتحها.

5. **بنك الكلمات والبطاقات الذكية (Vocab Bank & Flashcards):**
   - حفظ المفردات ومراجعتها بنظام البطاقات القلابة (Flashcards).
   - تحديد الكلمات المتقنة (Mastered Words).
   - دليل النطق الصوتي الفونيمات (IPA) وجمل تطبيقية واقعية.

6. **لعبة تحدي الكلمات المصوّرة (Picture Word Game):**
   - زر مركزي بارز في شريط التنقل السفلي، بمستوى سهل ومناسب للمبتدئين.
   - 351 لغزًا من مفردات المنهج، كل لغز مرفق بصورة كرتونية تعبّر عن الإجابة، مع المعنى العربي والنطق الصوتي.
   - تلميحات لكشف حرف أو إخفاء حروف غير موجودة، ولوحة مفاتيح عربية/إنجليزية مريحة.
   - فلاتر للمراحل الأربع ومستويات الصعوبة، وحفظ تلقائي للتقدم ونقاط XP وسلسلة الإجابات.
   - رسوم Twemoji مضمّنة داخل التطبيق وتعمل دون اتصال، مع سمة بصرية مستوحاة من الباندا.

7. **المعلم الذكي للمحادثة (AI English Tutor):**
   - محادثة إنجليزية طبيعية داخل التطبيق مع تصحيح لطيف للمفردات والقواعد، وترجمة عربية كاملة لكل رد.
   - بطاقات كلمات جديدة مع المعنى العربي والنطق، وزر لسماع الرد أو الكلمة بصوت الجهاز.
   - تدريب على النطق: يستمع التطبيق إلى محاولتك ويعرض تقييمًا تقريبيًا ونصيحة عربية لتحسين المخارج.
   - يتكيف الرد مع مستوى CEFR الحالي للمتعلم (A1–C1) ومرحلة المنهج، مع إمكانية تغيير المستوى يدويًا من رأس المحادثة.
   - سجل المحادثة يُحفظ محليًا على الجهاز، ومفتاح مزوّد الذكاء الاصطناعي يبقى على الخادم فقط ولا يُضمّن في APK.
   - يعمل المعلم فورًا عبر مزوّد مجاني احتياطي عند عدم إعداد مفاتيح، ويمكن ترقيته إلى DeepSeek عبر Cloudflare دون إعادة بناء التطبيق.

8. **نسخ احتياطي مشفّر ونقل آمن بين الأجهزة:**
   - من الإعدادات ← **حفظ واستعادة التقدم**، يُنشئ التطبيق ملفًا مشفّرًا بكلمة مرور تعمل دون إنترنت.
   - يستخدم `PBKDF2-SHA256` بـ 210,000 دورة، و`AES-256-GCM` بمفتاح ونونس عشوائيين، ولا يحفظ كلمة المرور ولا يرسلها إلى أي خادم.
   - يعرض معاينة للفروقات قبل الاستبدال، ويطلب موافقة صريحة، ويحفظ نسخة أمان محلية تسمح بالتراجع.
   - تشمل النسخة الملف الشخصي وتقدم الألعاب والإنجازات ونتائج الاختبارات، مع بقاء تقدم الدروس منفصلًا لكل لغة.
   - تُرفض الملفات التالفة أو المعدّلة أو ذات الإصدار غير المدعوم قبل تطبيق أي تغيير.

9. **شريط تنقل سفلي متوافق مع معايير اللمس:**
   - الرئيسية (Feed)
   - التصنيفات (Categories)
   - الكلمات (Vocab Bank)
   - الألعاب (Games) — الزر المركزي البارز
   - التقدم (Progress & Badges)
   - الإعدادات ودليل APK (Settings & Capacitor Guide)
   - زر عائم «المعلم AI» يفتح المحادثة من أي تبويب دون تغيير الزر المركزي للألعاب.

## 🔐 الصلاحيات وتثبيت APK

- يطلب التطبيق `INTERNET` للاتصال بالشبكة، و`RECORD_AUDIO` لتدريب النطق عند استخدام الميكروفون فقط. لم يعد يطلب `REQUEST_INSTALL_PACKAGES`.
- يتحقق زر التحديث من الإصدار الرسمي وبصمة SHA-256 المنشورة، ثم يفتح المتصفح لتنزيل حزمة APK. لا ينزّل التطبيق الحزمة داخليًا ولا يفتح مثبّت الحزم بنفسه؛ يظل التثبيت بموافقة المستخدم في Android.
- لا يطلب التطبيق صلاحية الوصول إلى جميع الملفات أو صلاحيات التخزين القديمة؛ النسختان الاحتياطيتان الجديدة والقديمة تستخدمان منتقي ملفات Android لحفظ ملف واحد فقط.
- التطبيق موقّع بمفتاح التوقيع الرسمي نفسه منذ الإصدارات السابقة. تغيّر الاسم الظاهر إلى Lin Go فقط، ويجب الحفاظ على هذا المفتاح لتعمل التحديثات فوق النسخ المثبتة.
- قد يعرض Play Protect تحذيرًا للتطبيقات المثبتة من خارج Google Play حتى لو كانت صلاحياتها محدودة؛ هذا يعتمد على سمعة التطبيق وإعدادات الجهاز. الحل الجذري لضمان تثبيت قياسي دون تحذير هو نشر التطبيق على Google Play.
- **أثناء الانتقال من 1.8.2 أو أقدم:** إن منع Play Protect التحديث الذي يبدأه التطبيق القديم، نزّل 1.8.3 من صفحة التحميل الرسمية وثبّته يدويًا. لا تعطّل Play Protect.

### مكتبة الصوت المضمّنة

تُولَّد أصوات الدروس مرة واحدة أثناء التطوير بالأمر `npm run speech:generate` (السكربت `scripts/generate-speech-library.ts`)، ثم تُضمَّن داخل البناء في `public/audio/tts/<voice>/<hash>.ogg` فلا يحتاج التطبيق إلى تنزيل أي شيء عند الاستخدام.

- الأصوات من نموذج [Kokoro-82M ONNX](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX) مفتوح الأوزان (رخصة Apache-2.0): `af_heart` و`am_michael` للإنجليزية. لا يتضمن النموذج صوتًا فرنسيًا مضمّنًا، لذا تستخدم النصوص الفرنسية صوت الجهاز كخطة بديلة.
- اسم الملف = تجزئة FNV-1a 64-bit للنص بعد التطبيع (دالة `speechClipHash` في `src/services/speechClip.ts`)؛ يجب أن يتفق السكربت والتطبيق حرفيًا وإلا لن يُعثر على المقطع.
- رموز النطق (IPA) مثل `/æ/` و`/b/` تُحوَّل عند التوليد إلى صياغة طبيعية مثل «A as in Apple» بدل أن ينطقها المحرك «slash ... slash»، بينما يبقى النص المعروض كما هو.
- السكربت يولّد الصوتين الإنجليزيين لكل نص (لأن الدرس والمفردات واختبار تحديد المستوى قد يطلبون صوتًا مختلفًا)، ويتخطّى المقاطع الموجودة، فيمكن إيقافه واستئنافه بأمان، ويدعم `--limit N` لتجربة سريعة.
- الترميز بـ`ffmpeg` (`libopus`، ‏24 kbps، أحادي القناة، إعداد `voip`) وهو الأنسب للكلام البشري. يتوقع السكربت `tools/ffmpeg-tool/node_modules/ffmpeg-static/ffmpeg.exe` أو المسار في `FFMPEG_PATH`.
- `npm run speech:check` يتحقق من وجود كل المقاطع المطلوبة (4,558 مقطعًا عبر المراحل الأربع) ومن سلامة نص التوليد (لا رموز IPA تُقرأ حرفيًا)، وأي نص جديد بلا مقطع يوقف البناء. يستخدم `npm run build` هذا الفحص الصارم الآن بعد اكتمال مكتبة الصوت.
- لم يعد التطبيق يحمّل نموذج Kokoro أو أوزان ONNX/WASM (كانت نحو 20 ميجابايت)، فانخفض حجم الحزمة وزمن الإقلاع.
- في Android لا يوفّر WebView واجهة Web Speech API، لذا يستخدم درس النطق إضافة `SpeechRecognitionPlugin` الأصلية (`android/app/src/main/java/com/englishtok/app/`) وخدمة `SpeechRecognizer`. يتضمن البيان إذن `RECORD_AUDIO` ويُطلب من المستخدم عند أول ضغط على الميكروفون.

### إعداد المعلم الذكي (AI Tutor)

واجهة المحادثة موجودة في `src/components/chat/ChatTab.tsx`، وطلباتها تمر عبر `api/chat.ts` على الخادم. لا يصل مفتاح المزوّد إلى المتصفح أو APK إطلاقًا.

**التشغيل الفوري (بدون مفاتيح):** إذا لم تُضف أي مفتاح، يستخدم الخادم تلقائيًا مزوّدًا مجانيًا احتياطيًا هو Pollinations.AI بطراز GPT-OSS 20B. هذا يجعل المحادثة والترجمة والتصحيح تعمل مباشرة بعد النشر، لكنه خدمة عامة best-effort قابلة للتوقف أو البطء، ولا ينبغي إرسال معلومات شخصية حساسة خلالها. لتعطيله تمامًا عيّن `AI_FREE_FALLBACK=false`.

**ترقية إلى DeepSeek مجانًا عبر Cloudflare (موصى بها):**

1. أنشئ حساب [Cloudflare](https://dash.cloudflare.com/) مجانيًا، ثم أنشئ API Token بصلاحية **Workers AI**. احتفظ بـ **Account ID** و**API Token**.
2. أضف متغيرات البيئة التالية إلى مشروع Vercel في Production وPreview:
   ```text
   AI_PROVIDER=cloudflare
   CLOUDFLARE_ACCOUNT_ID=...
   CLOUDFLARE_AI_TOKEN=...
   CLOUDFLARE_AI_MODEL=@cf/deepseek-ai/deepseek-r1-distill-qwen-32b
   ```
3. أعد نشر المشروع على Vercel. للتحقق من الإعداد افتح:
   ```text
   https://www.lingo.com/api/chat
   ```
   ويجب أن يعيد JSON يحتوي `configured: true` واسم طراز DeepSeek. عند وجود مفتاح Cloudflare يصبح هو المزوّد الأساسي تلقائيًا ويتوقف استخدام المزوّد المجاني الاحتياطي.
4. بديل مدفوع اختياري: عيّن `AI_PROVIDER=deepseek` وأضف `DEEPSEEK_API_KEY` (أو استخدم OpenRouter عبر `AI_PROVIDER=openrouter` و`OPENROUTER_API_KEY`). لا يلزم إعادة بناء APK عند تغيير المزوّد أو المفتاح؛ يكفي نشر الخادم.

ملاحظات:
- الطبقة المجانية في Cloudflare لها حصة يومية محدودة، وقد تتوقف الخدمة مؤقتًا عند استهلاكها. يمكن الانتقال إلى DeepSeek المدفوع لاحقًا دون تغيير التطبيق.
- المزوّد الاحتياطي المجاني لا يحتوي مفتاحًا ولا يضمن الخصوصية أو الاستمرارية؛ للاستخدام الجاد أضف Cloudflare أو DeepSeek. يمكن ضبط الطراز عبر `POLLINATIONS_MODEL` (الافتراضي `openai-fast`).
- يتضمن الخادم حدًا افتراضيًا قدره 8 رسائل في الدقيقة و40 رسالة في الساعة لكل عنوان IP، مع تخزين مؤقت في Upstash Redis إن كانت متغيرات `KV_REST_API_URL`/`KV_REST_API_TOKEN` مضبوطة.
- تطبيق Android يستدعي الخادم على `https://www.lingo.com` افتراضيًا. إذا نُشر الموقع على نطاق آخر، ابنِ APK مع `VITE_API_BASE_URL=https://your-domain.example`. في الويب تُستخدم نفس أصول الموقع (`/api/chat`).
- تقييم النطق تقريبي لأنه يعتمد على النص الذي يتعرف عليه الميكروفون، وليس على تحليل صوتي احترافي. الصوت نفسه يُشغّل عبر `TextToSpeechPlugin` الأصلي في Android، ويبقى صوت المتصفح خطة احتياطية على الويب.

## 📲 خطوات تحويل المشروع إلى تطبيق أندرويد (APK) باستخدام Capacitor

تم تجهيز ملف `capacitor.config.json` في المشروع. لتحويله محلياً على جهازك إلى ملف APK، اتبع الخطوات التالية:

### 1. تثبيت حزم Capacitor:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
```

### 2. بناء ملفات الويب الإنتاجية:
```bash
npm run build
```

### 3. إضافة منصة أندرويد:
```bash
npx cap add android
```

### 4. مزامنة التغييرات:
```bash
npx cap sync android
```

### 5. فتح المشروع في Android Studio لتوليد الـ APK:
```bash
npx cap open android
```
داخل **Android Studio**:
- اذهب إلى القائمة: `Build` ➔ `Build Bundle(s) / APK(s)` ➔ `Build APK(s)`.
- سينتج لك ملف `app-debug.apk` أو `app-release.apk` جاهزاً للتثبيت المباشر على أي هاتف أو تابلت أندرويد.
