# Stage extensions — lessons 51–100

This folder contains the second expansion wave: **200 lessons**, 50 per stage,
bringing each CEFR stage from 50 to **100 lessons** (400 total).

The files are generated by:

```bash
npx tsx scripts/generate-extension-lessons.ts
```

Each lesson links two adjacent base lessons and reuses four existing vocabulary
rows, including their example sentences and IPA. This is deliberate:

- every example already has a bundled `af_heart` and `am_michael` audio clip;
- the offline APK grows by only the ten new framing lines per stage;
- learners get spaced repetition of known words in fresh combinations instead
  of a second disconnected word list.

The generated lessons add new titles, Arabic descriptions, objectives, model
structures and framing dialogue, plus a fill-in question that is displayed but
not spoken (`skipFillAudio: true`). The generator is idempotent: it only reads
base lessons 1–50, so it can be re-run after changing the framing templates.

Do not hand-edit the generated files unless the same change is made in the
generator; running it again overwrites them.
