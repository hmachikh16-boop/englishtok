# Lin Go Gold Control

تطبيق سطح مكتب محلي لإدارة أكواد **Lin Go Gold** ومتابعة المستخدمين والتحقق من الأكواد الصالحة.

## التشغيل

- الملف الجاهز: `LinGo Gold Control.exe` على سطح المكتب.
- يمكن تشغيل نسخة البناء من: `desktop/lin-go-control/bin/LinGoGoldControl.exe`.
- لا يحتاج التطبيق إلى تثبيت أو صلاحيات مدير، ولا إلى اتصال بالإنترنت.

## الوظائف

- إنشاء أكواد Gold بأعداد ومُدد وحدود أجهزة مختلفة.
- نسخ الأكواد أو حفظها في ملف CSV فور إنشائها.
- تفعيل كود يدويًا وتعيينه لمستخدم وجهاز.
- تعديل الملاحظات، إلغاء التفعيل، تمديد 30 يومًا، إلغاء الكود أو إعادة تنشيطه.
- البحث والتصفية حسب الحالة، مع عدّادات للأكواد الصالحة والمفعّلة والمستخدمين وتنبيهات الانتهاء القريب.
- فحص كود سريع يعرض الحالة والمستخدم والجهاز وتاريخ الانتهاء.
- تصدير CSV، نسخة احتياطية JSON، واستيراد/دمج نسخة احتياطية.
- حفظ تلقائي في قاعدة بيانات محلية، مع نسخة `.bak` عند كل حفظ.

## مكان البيانات

```text
%LOCALAPPDATA%\LinGoGoldControl\licenses.json
```

المسار يظهر داخل التطبيق، ويمكن فتح المجلد أو نسخ المسار من بطاقة **بيانات التحكم**.

## البناء من المصدر

المتطلب الوحيد هو .NET Framework 4.8 الموجود أصلًا في Windows.

```powershell
cd desktop/lin-go-control
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

البناء ينتج:

```text
bin\LinGoGoldControl.exe
```

وينسخه إلى سطح المكتب باسم `LinGo Gold Control.exe`، ما لم تستخدم `-NoCopy`.

## حدود النسخة الحالية

هذه نسخة **محلية** بالكامل. لا ترسل الأكواد أو بيانات المستخدمين إلى أي خادم، ولا تتصل حتى الآن بخدمة تفعيل داخل تطبيق Android. الأكواد المسجلة هنا هي سجل إدارة محلي، ويمكن تصديرها/نسخها احتياطيًا. عند إضافة API تفعيل لاحقًا يمكن استخدام قاعدة البيانات المحلية كمصدر للترحيل.

تطبيق Gold على Android ما زال في مرحلة المعاينة، ولا يقبل إلا كود المعاينة `LINGO-GOLD-DEMO-2026`. التفعيل التجاري الفعلي مرتبط ببناء خادم تراخيص.

## ملاحظات أمنية

- لا تضع كلمة مرور أو أسرارًا في الملاحظات.
- احفظ نسخة JSON احتياطية دوريًا على وسيط موثوق.
- ملف التطبيق غير موقّع بشهادة تجارية؛ قد يظهر تحذير SmartScreen عند أول تشغيل.
